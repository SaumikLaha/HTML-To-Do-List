# ✅ Internship Project 2 - HTML To-Do List  
**Frontend Web Development Internship – 1Stop.ai**

---

## 📌 Project Overview  
The **HTML To-Do List Application** is a simple and interactive web-based task manager that allows users to add, view, and delete tasks.  
It is built using **pure HTML, CSS, and JavaScript**, making it lightweight and beginner-friendly.

---

## 🎯 Objective  
To develop a basic task management system using core web technologies that helps users organize and track their daily activities efficiently.

---

## 🛠️ Tech Stack  
| Technology | Purpose |
|------------|---------|
| **HTML**   | Structure of the webpage |
| **CSS**    | Styling and UI design |
| **JavaScript** | Task operations (Add/Delete/Store) |

---

## 🚀 Features  
✅ Add new tasks  
✅ Delete tasks individually  
✅ Simple and user-friendly interface  
✅ Works in all modern browsers  
✅ Fully responsive layout
